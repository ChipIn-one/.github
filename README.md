# ChipIn-one/.github

Organisation-wide defaults for every `ChipIn-one` repository. GitHub applies them to any repo that
has no local file of the same kind; a local file overrides the default for that repo only.

| Path | Purpose |
| --- | --- |
| `.github/ISSUE_TEMPLATE/` | issue forms: bug, enhancement, docs, tests, research (moved from `chipin-backend` on 2026-09-08) |
| `github-issue-schema.md` | the task model behind the forms — labels, fields, lifecycle |

Product and engineering documentation lives in
[`chipin-knowledge-base`](https://github.com/ChipIn-one/chipin-knowledge-base); this repo holds
only GitHub tooling shared across repos.
